# Community health files

Default community files for the open-source projects at
[Pareto Cybernetics](https://paretocybernetics.com).
GitHub uses these files when a repository does not provide its own:

- [Code of conduct](CODE_OF_CONDUCT.md)
- [Support guide](SUPPORT.md)
- [Bug report](.github/ISSUE_TEMPLATE/bug_report.yml)
- [Feature request](.github/ISSUE_TEMPLATE/feature_request.yml)
- [Pull request template](.github/pull_request_template.md)

The [project directory](https://github.com/michael-berardi/michael-berardi)
lists the public repositories. This account uses that repository for its profile;
there is no separate organization profile in this repository.

## Privacy

This repository holds community files only: it runs no code and stores nothing.
The projects it links to run locally with no telemetry or analytics. Apps and
command-line tools make one anonymous update check a day, which you can turn off.
Any other network use is a feature you set up, such as a model provider you choose.
Each project's README has its own Privacy section with the details.
